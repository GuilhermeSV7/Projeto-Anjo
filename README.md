# MiniJogos — Avaliação de Atenção

Plataforma mobile-first em HTML, CSS e JavaScript.

## Semáforo
- Duração: 60 segundos.
- O semáforo principal controla somente a via **HORIZONTAL (esquerda ↔ direita)**.
- A via **VERTICAL** continua passando de forma independente.
- O participante toca no semáforo para abrir/fechar a horizontal.
- Cada carro horizontal liberado vale 1 ponto.
- Não há vidas, falhas ou game over.
- Resultado: pontos totais e média de pontos por segundo.

## Mais ou Menos
- Carta vertical inspirada na experiência de jogos de decisões por cartas.
- 20 rodadas.
- Arraste a carta para a esquerda/direita ou use os botões.
- Resultado: acertos, erros e precisão.
